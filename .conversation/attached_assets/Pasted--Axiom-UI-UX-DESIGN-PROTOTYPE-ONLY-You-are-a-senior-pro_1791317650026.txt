# Axiom — UI/UX DESIGN PROTOTYPE ONLY

You are a senior product designer and frontend UI engineer specializing in premium SaaS products.

Your task is **NOT to build the Axiom application**.

Your task is to create a **complete visual UI/UX prototype** that shows exactly what the Axiom product should look like.

The attached project documents are the source of truth.

READ THE ATTACHED DOCUMENTS FIRST.

Do not invent product functionality that is not supported by the documents.

---

# 1. WHAT YOU ARE BUILDING

Build a high-fidelity **UI/UX concept prototype** for:

**Axiom**

An AI-powered academic exam-question generation platform for university instructors.

The main product journey is:

Instructor
→ Dashboard
→ Course
→ Course Materials
→ Style Profile
→ Generate Exam
→ AI Generation Progress
→ Review Questions
→ Edit / Approve / Reject
→ Export Exam

The final result should allow someone to open the HTML file and visually understand the entire product.

This is a **design prototype**, not a real application.
